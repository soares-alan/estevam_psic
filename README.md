# Landing Page - Estevam Holpert Psicólogo

Landing page profissional para o psicólogo Estevam Holpert, desenvolvida com React, TypeScript e Tailwind CSS.

## Stack de Tecnologia

- **Framework/Lib**: React com Vite
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS
- **Internacionalização**: i18next e react-i18next

## Estrutura do Projeto

```
src/
├── components/         # Componentes reutilizáveis
│   ├── layout/         # Componentes de layout (Header, Footer)
│   ├── sections/       # Seções da landing page
│   └── ui/             # Componentes UI (Button, Card, etc.)
├── pages/              # Páginas da aplicação
├── types/              # Tipagens TypeScript
├── assets/             # Recursos estáticos
├── locales/            # Arquivos de tradução
│   ├── pt-BR/          # Português do Brasil
│   └── en-US/          # Inglês dos Estados Unidos
├── i18n.ts             # Configuração do i18next
└── App.tsx             # Componente principal
```

## Funcionalidades

- Design responsivo e moderno
- Suporte a múltiplos idiomas (Português e Inglês)
- SEO otimizado com React Helmet Async
- Navegação suave com scroll automático
- Interface intuitiva e acessível

## Comandos Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Gera a versão de produção
- `npm run preview` - Visualiza a versão de produção localmente

## Como Iniciar

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`
4. Acesse http://localhost:3000
